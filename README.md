# Fronx — E-commerce Frontend

Proyecto de tienda online construido con React. El repositorio sirve como práctica de desarrollo frontend basado en componentes, navegación entre vistas y presentación de productos dentro de una experiencia de compra.

## Objetivos del proyecto

- Construir una interfaz de comercio electrónico con React.
- Organizar la UI mediante componentes.
- Explorar navegación entre vistas con React Router.
- Utilizar Tailwind CSS para el sistema de estilos.
- Incorporar iconografía y notificaciones visuales.

## Tecnologías

- React 18
- JavaScript
- Tailwind CSS
- React Router
- React Icons
- React Hot Toast
- Create React App

## Requisitos

- Node.js y npm instalados.

## Instalación

```bash
git clone https://github.com/miguelagcz/Fronx.official.git
cd Fronx.official
npm install
npm start
```

La aplicación estará disponible en la dirección local que muestre Create React App, normalmente http://localhost:3000.

## Compilar para producción

```bash
npm run build
```

## Qué demuestra

Práctica de React, estructura de componentes, navegación del lado del cliente y estilizado con utilidades CSS. La disponibilidad de pagos reales, autenticación o persistencia de pedidos depende de que exista una integración de backend correspondiente.
